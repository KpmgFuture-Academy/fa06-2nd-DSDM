### 2. 프로젝트 주제
- **주제:** 신용카드 고객 세그먼트 분류 AI 알고리즘 및 대시보드 개발  
- **설명:** 고객의 신용정보, 승인매출, 청구, 잔액, 채널, 마케팅, 성과 등 데이터를 기반으로 고객 세그먼트(A~E)를 분류하는 AI 알고리즘을 개발하고, 전사 실무자가 활용할 수 있는 단일 대시보드를 구축.  

### 3. 문제 정의 및 목적
- **문제 정의:**  
  - 고객 분류 기준이 부서별로 제각각 → 데이터 불일치  
  - 실무자가 매번 개발팀에 데이터 추출 의존 → 업무 지연, 기회 손실  
  - 기존 분석은 사후적이고 부분적 → 빠른 의사결정 곤란  
- **목적:**  
  - 전사 공통 세그먼트 체계를 도입해 일관된 기준 확보  
  - AI 기반 분류 모델로 고객 세그먼트 예측 정확도 향상  
  - 대시보드에서 KPI·리스크·행동 데이터를 통합 제공  
  - 실무자의 업무 효율 +40%, 데이터 요청 TAT -60% 달성  

### 4. 핵심 타겟

- **1차 타겟 고객 (조직 레벨)**  
  - 카드사 내부 **전사 경영진 및 전략 부서** (기획, 경영지원, 리스크 관리 총괄 등)  
  - 기존에는 부서별로 분리된 대시보드만 존재하여 전사 단위 시각화가 불가능했음  

- **End-User (개인 레벨)**  
  - 전사적 흐름과 부서 간 비교를 확인해야 하는 **경영진·분석가**  
  - 빠른 고객군 파악과 타깃 액션이 필요한 **마케터/리스크 매니저**  
  - 데이터 분석 도구에 직접 접근하기 어려운 **일선 실무자**  

- **통합 대시보드의 역할**  
  - 부서별 대시보드를 대체하는 것이 아니라, 그 위 상위 레이어(메타 뷰)로 동작  
  - 각 부서의 개별 지표를 **공통 세그먼트 기준으로 집계/표준화**  
  - 결과적으로 “부서별 분리된 뷰 → 전사 통합 메타 뷰”를 연결하여  
    **일관된 의사결정, 빠른 협업, 데이터 기반 경영**을 지원


### 5. 서비스 주요 기능
- 공통 세그먼트 산출 (A~E 등급화)  
- 메인 대시보드: 세그먼트별 KPI, 리스크, 행동패턴  
- LLM 기반 인사이트 요약: 차트 설명 및 5줄 리포트 제공  
- 리스크 예측: 승인거절/연체/한도초과 신호 탐지  
- (추후) 이탈률 예측 및 고객 맞춤 액션 추천

## 📊 데이터 정의 및 수집 방식

### 1. 데이터 정의

**데이터 소스**  
- 본 프로젝트에서는 카드사 고객 행동분석 및 분류 모델링 목적의 익명화된 고객정보 데이터셋을 활용하였습니다.
- 실제 고객 식별 정보는 포함되어 있지 않으며, 분석 실습 및 모델링을 위해 가공된 데이터입니다.

**데이터 구성 (원본 폴더 구조)**  
1. 회원정보  
2. 신용정보  
3. 승인매출정보  
4. 청구입금정보  
5. 잔액정보  
6. 채널정보  
7. 마케팅정보  
8. 성과정보  

**주요 컬럼 카테고리**
- **고객 특성**  
  - ID, 성별, 연령, 지역, 가입일
- **이용 정보 (거래 패턴)**  
  - 총이용금액_B0M, 총이용건수_B0M  
  - 카드이용한도액, 업종별 이용금액(신판, 체크, 현금서비스 등)
- **리스크 지표**  
  - 승인거절률_B0M  
  - 연체여부, 연체금액_B0M, 연체발생횟수
- **참여도 / 활동성**  
  - 모바일로그인_30D  
  - 마케팅반응률_90D  
  - 캠페인 쿠폰 사용률
- **혜택 / 포인트**  
  - 포인트 적립_B0M, 포인트 소멸_B0M  
  - 혜택수혜율, 연회비 납부 여부

---

### 2. 데이터 수집·전처리 방식

**수집 방식**  
- 카드사 고객 행동분석 및 분류 모델링 목적의 익명화된 고객정보 데이터셋 수집

**전처리 과정**  
1. 각 카테고리(회원/신용/승인매출/청구입금/잔액/채널/마케팅/성과) 데이터를 로드  
2. `ID` + `기준년월`을 키로 **통합 데이터프레임 병합**  
3. 월별 스냅샷 연결 → 시계열 분석 가능하도록 구성  
4. 불필요 컬럼 제거 및 결측치 처리  
5. 최종 통합 데이터셋 생성 → 모델링·분석 활용

### 사용법
1. 사이드바에서 메인 탭과 세부 탭을 선택합니다.
2. 글로벌 필터(기간, 연령대, 지역, 채널, 카드유형, 세그먼트)를 설정합니다.
3. 각 서브 탭의 차트와 표를 탐색하고, 필요한 경우 CSV로 다운로드합니다.
4. 리스크 분석 탭에서 GPU 가속을 활성화하여 대용량 계산을 테스트할 수 있습니다.

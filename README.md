## 📌 프로젝트 계획서

### 1. 프로젝트 정보

* 프로젝트 기간: 2025-09 \~ 2025-10 (MVP 파일럿 기준)
* 팀 명: TBD (예: Insight Union)
* 참여 인원: PM 1, BE 1, DS 1, FE 1, 디자인 0.5

### 2. 프로젝트 주제

* **주제:** 신용카드 고객 세그먼트 분류 AI 알고리즘 및 대시보드 개발
* **설명:**
  고객의 신용정보, 승인매출, 청구, 잔액, 채널, 마케팅, 성과 등 데이터를 기반으로
  고객 세그먼트(A\~E)를 분류하는 AI 알고리즘을 개발하고,
  전사 실무자가 활용할 수 있는 단일 대시보드를 구축.

### 3. 문제 정의 및 목적

* **문제 정의:**

  * 고객 분류 기준이 부서별로 제각각 → 데이터 불일치
  * 실무자가 매번 개발팀에 데이터 추출 의존 → 업무 지연, 기회 손실
  * 기존 분석은 **사후적**이고 **부분적** → 빠른 의사결정 곤란

* **목적:**

  * **전사 공통 세그먼트 체계**를 도입해 일관된 기준 확보
  * **AI 기반 분류 모델**로 고객 세그먼트 예측 정확도 향상
  * **대시보드**에서 KPI·리스크·행동 데이터를 통합 제공
  * 실무자의 **업무 효율 +40%, 데이터 요청 TAT -60%** 달성

### 4. 핵심 타겟

* **1차 타겟 고객:**
  카드사 내부 부서 (마케팅, 리스크 관리, 영업, 고객서비스, 기획)
* **End-User:**

  * 데이터 분석에 직접 접근하기 어려운 실무자
  * 빠른 고객군 파악과 타깃 액션이 필요한 마케터/리스크 매니저
  * 경영진 및 분석가 (의사결정 참고용)

### 5. 서비스 주요 기능

1. **공통 세그먼트 산출** (A\~E 등급화)
2. **메인 대시보드**: 세그먼트별 KPI, 리스크, 행동패턴
3. **LLM 기반 인사이트 요약**: 차트 설명 및 5줄 리포트 제공
4. **리스크 예측**: 승인거절/연체/한도초과 신호 탐지
5. (추후) 이탈률 예측 및 고객 맞춤 액션 추천

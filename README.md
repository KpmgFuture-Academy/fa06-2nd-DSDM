# 신용카드 고객 세그먼트 대시보드

---

## 🎯 프로젝트 목적

* **전사 공통 목표**

  * 전사 모든 부서가 활용할 수 있는 **표준 고객 세그먼트 체계**와 **데이터 대시보드**를 구축하여,
    고객 관리 및 업무 효율을 **40% 이상 향상**시키고 **일관된 의사결정**을 지원합니다.

* **AI 모델링 목표**

  * 금융산업의 디지털 전환 속에서, 카드사 고객 데이터(신용정보, 승인매출, 청구, 잔액, 채널, 마케팅, 성과 등)의 가치를 극대화합니다.
  * 고객의 일정 기간 데이터를 기반으로 **신용카드 고객 세그먼트(Segment)를 예측·분류하는 AI 알고리즘**을 개발합니다.
  * 정확한 세그먼트 분류를 통해 **마케팅 전략 정교화, 리스크 관리 고도화, 고객 맞춤형 서비스 제공**에 기여합니다.

* **궁극적 지향점**

  * 데이터 기반의 **자동화된 고객 분류 & 인사이트 제공** → 실무자가 즉시 활용 가능한 **액션 기반 대시보드** 완성
  * 고객 경험(CX) 개선과 동시에, 카드사의 **수익성 강화·리스크 관리·규제 대응**을 모두 충족하는 플랫폼 구축

---

## 📌 Overview

* **문제/기회**: 고객 세그먼트 부재 → 매번 개발팀 의존 → 지연, 불일치, 비효율 발생
* **핵심 가설**: 공통 세그먼트 체계 + 단일 대시보드 제공 시 **부서별 업무 효율 +40%**
* **MVP 범위**

  * 세그먼트 산출 (A\~E)
  * 메인 대시보드 (개요 / KPI / 리스크 / 소비 패턴)
  * LLM 기반 차트 분석 및 인사이트 제공
* **성공 지표**

  * NSM: 대시보드 MAU, 고객사 이탈율
  * 선행: 요청→응답 TAT -60%, WAU ≥ 100, TTV < 10분
* **기간·리소스**: MVP 1주 (PM 1, BE 1, DS 1, FE 1, 디자인 0.5)
* **리스크 대응**: 데이터 딕셔너리 & 검증 파이프라인 / 최소수집 & 암호화 / 권한 관리

---

## 🎯 Goals

* **제품 목표**: 고객관리 업무 효율 **40% 향상**
* **사업 목표**: 일관된 체계 정립 → 만족도↑ → 교차판매/유지율↑ → 매출↑
* **비범위**: 일 단위 실시간 모니터링, 정책 최적화 시뮬레이션, 외부 채널 오케스트레이션

---

## 👥 Target Users

* **페르소나**: 마케팅 / 리스크 / CS / 영업기획 실무자, PM, 애널리스트
* **니즈 (JTBD)**: “고객 현황을 즉시 파악하고 빠르게 액션으로 이어가고 싶다.”
* **세그먼트 기준**: 가입기간, 이용금액, 이용건수, 한도이용률, 승인거절, 연체, 채널 활용
* **규제/보안**: 비식별화, 접근권한 관리, 로그 기록

---

## 📚 User Stories & Use Cases

* **실무자**로서, **세그먼트별 KPI/리스크/행동패턴**을 한 화면에서 보고 싶다.
* **유즈케이스**

  1. 세그먼트별 KPI 비교 → 고가치/고위험군 식별
  2. 리스크 신호 모니터링 → 사전 대응
  3. 채널 반응/소비 패턴 분석 → 캠페인 타깃팅

## ✅ Requirements

### 기능 (FRD)

* **Must**

  * 공통 세그먼트 산출 파이프라인
  * 메인 대시보드 (개요/KPI/트렌드)
  * 리스크/행동 요약
  * LLM 리포트 v0
* **Should**: 이탈률 예측, 지표 근거 링크
* **Could**: 간단한 추천 액션
* **Won’t**: 실시간 모니터링, 자동 캠페인 발송

### 비기능 (NFR)

* 성능: 주요 차트 조회 < 300ms (P95)
* 보안: 암호화, RLS, 로깅
* 가용성: SLO 99.5%
* 운영: 버전 관리, 롤백 플래그

## 🛠 Architecture & Data

### UX 정보 구조

* 메인분석: 세그먼트 개요 / KPI / 트렌드 / 리포트
* 리스크 분석: 거절/연체/한도/현금서비스
* 행동 & 마케팅: 앱·웹 이용 / 채널 반응 / 캠페인 / 업종 소비

### 데이터 모델

* 주요 테이블: `customers`, `usage_monthly`, `risk_monthly`, `engagement`, `campaigns`
* 파생 지표: 한도이용률, ARPU, MoM/YoY 증감률
* 이벤트: `dash_view`, `segment_filter`, `download_report`, `chart_drilldown`

### 기술 스택

* **FE**: Streamlit + Plotly/ECharts
* **BE/ETL**: Python, Airflow/Cloud Scheduler
* **ML**: CatBoost (세그/이탈), 지표: AUC/F1
* **DB**: Cloud SQL (Postgres)
* **보안**: SSO(OIDC), Row-Level Security, KMS

## 🤖 AI/ML

* **세그먼트 분류**

  * 입력: 가입기간, 이용금액/건수, 한도이용률, 승인거절, 연체, 채널활동 등
  * 지표: AUC ≥ 0.75, F1 Top-K
  * 가드레일: 민감속성 제외, SHAP 설명, 휴리스틱 백업
* **이탈률 예측**

  * 고위험군 사전탐지율 +20%
  * 잘못된 경보율 ≤5%
  * HITL: 1차 AI 제안 → 2차 검수 승인/반려

---

## 🧪 Experiment & Metrics

* **주가설**: 대시보드 도입 시 업무 효율 ≥ 40%
* **실험 설계**: 부서 단위 A/B (파일럿 2 vs 대조 2)
* **지표**

  * Leading: TAT, WAU/DAU, TTV
  * Lagging: 승인거절/연체 개선, 리텐션, 교차판매
